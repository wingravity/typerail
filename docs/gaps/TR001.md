# TR001: File not checked

| | |
|---|---|
| Kind | A typerail finding, not a gap in TypeScript |
| Checked by | typerail |
| Priority | P0: process can go down |

## What it means

This is not a gap in TypeScript. ESLint could not parse or type-check the file, so no rule ran on it. A file outside the tsconfig used for type information is the most common cause.

## How typerail detects it

`typerail report` lists the parse error as a P0 finding, because every other check is silently skipped for the file.

## How to fix it

Fix the parse error, or add the file to the tsconfig that ESLint uses (`parserOptions.projectService`). Exclude it in `eslint.config.js` if it should not be linted.
