# TR103: Method parameter bivariance

| | |
|---|---|
| Status | Open in TypeScript 6.0.3 |
| Checked by | `typerail/no-method-bivariance` |
| Priority | P1: silent wrong result |

## Example

TypeScript accepts this code under `@wingravity/typerail/tsconfig.json`:

```ts
interface Animal {
  name: string;
}

interface Dog extends Animal {
  bark(): string;
}

const rex: Dog = { name: "Rex", bark: () => "woof" };

interface Handler<T> {
  handle(value: T): string;
}

export function proof(): string {
  const dogHandler: Handler<Dog> = { handle: (dog) => dog.bark() };
  const animalHandler: Handler<Animal> = dogHandler;
  return animalHandler.handle({ name: "Tom" });
}
```

At runtime: `TypeError: dog.bark is not a function`

The example is [`test/gaps/TR103.ts`](../../test/gaps/TR103.ts). The test suite checks that TypeScript still accepts it and that it still fails when run.

## Why TypeScript allows it

`strictFunctionTypes` checks function parameters contravariantly, but only for function types. Parameters of methods (`handle(value: T): void`) and constructors are still checked bivariantly, so a method that needs a `Dog` is accepted where one that takes any `Animal` is expected. TypeScript keeps this so that built-in types such as `Array<T>` stay covariant. The same rule makes `Map<string, Dog>` assignable to `Map<string, Animal>` and `Set<Dog>` to `Set<Animal>`.

## How typerail detects it

`typerail/no-method-bivariance` reports a value assigned, passed, returned or stored where one of its methods could be called with an argument its own parameter type does not accept. It checks methods declared in project code and the writing methods of built-in collections (`Set.add`, `Map.set` and their weak versions). Read methods of built-in types, such as `ReadonlySet.has`, are not reported.

## How to fix it

Declare callback members as function properties (`handle: (value: T) => void`), which are checked strictly, or declare the type parameter invariant (`interface Handler<in out T>`). Accept `ReadonlySet` or `ReadonlyMap` when the callee only reads.
