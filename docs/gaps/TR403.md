# TR403: Method called without its object

| | |
|---|---|
| Status | Open in TypeScript 6.0.3 |
| Checked by | `@typescript-eslint/unbound-method` |
| Priority | P2: request fails |

## Example

TypeScript accepts this code under `typerail/tsconfig.json`:

```ts
class Counter {
  private count = 0;

  increment(): number {
    this.count += 1;
    return this.count;
  }
}

export function proof(): number {
  const counter = new Counter();
  const increment = counter.increment;
  return increment();
}
```

At runtime: `TypeError: Cannot read properties of undefined (reading 'count')`

The example is [`test/gaps/TR403.ts`](../../test/gaps/TR403.ts). The test suite checks that TypeScript still accepts it and that it still fails when run.

## Why TypeScript allows it

A method read from an object (`const increment = counter.increment`) loses its `this`. TypeScript does not check `this` unless the method declares a `this` parameter.

## How typerail detects it

`@typescript-eslint/unbound-method` reports class methods that are referenced without being called on their object.

## How to fix it

Call the method on its object, bind it (`counter.increment.bind(counter)`), or use an arrow function property.
