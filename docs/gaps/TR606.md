# TR606: Missing side-effect import

| | |
|---|---|
| Status | Open in TypeScript 6.0.3 |
| Checked by | `noUncheckedSideEffectImports` in `@wingravity/typerail/tsconfig.json` |
| Priority | P0: process can go down |

## Example

TypeScript accepts this code when `noUncheckedSideEffectImports` is off:

```ts
import "./TR606-polyfill.js";

export function proof(): string {
  return "loaded";
}
```

At runtime: `Error [ERR_MODULE_NOT_FOUND]: Cannot find module '.../TR606-polyfill.js'`

The example is [`test/gaps/TR606.ts`](../../test/gaps/TR606.ts). The test suite checks that TypeScript still accepts it and that it still fails when run.

## Why TypeScript allows it

TypeScript does not resolve side-effect imports (`import "./polyfill"`) unless `noUncheckedSideEffectImports` is on, so a misspelled or deleted file compiles and the module fails when it loads.

## How typerail detects it

`@wingravity/typerail/tsconfig.json` enables `noUncheckedSideEffectImports`. `typerail report` lists a project that turns it off.

## How to fix it

Enable the flag and fix the import path.
